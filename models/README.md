# `models/` — Trained Model Artifacts

## Purpose

Stores trained model artifacts used by the fog layer for real-time anomaly detection inference.

## Subdirectory

### `lstm_autoencoder/`

Contains all artifacts produced by the model training pipeline (notebook `3-Model_Training.ipynb`) and evaluation pipeline (notebook `4-Model_Evaluation.ipynb`):

- **`model.keras`** — The trained LSTM Autoencoder model in Keras format. Architecture: two LSTM layers (64 → 32 units encoder, mirrored decoder). Input shape: `(60, 2)` representing a 60-timestep window of 2 features (HR, SpO2).
- **`best_model.keras`** — Best model checkpoint saved during training (by validation loss).
- **`scaler.pkl`** — Serialised `MinMaxScaler` (scikit-learn) fitted on training data only. Used to normalise inference inputs identically to training.
- **`config.json`** — Full training configuration and evaluation metrics:
  - Train/test patient split (42 train, 10 test).
  - Window size (60), step size (1), features (`HR`, `SpO2`).
  - Model architecture and hyperparameters.
  - Training stats: 16 epochs, best validation loss `0.00168`.
  - Anomaly threshold: p95 of training reconstruction error (`0.00277`).
  - Evaluation results: precision `0.334`, recall `1.0`, F1 `0.501`, ROC-AUC `1.0`, PR-AUC `1.0`.
  - Anomaly types injected for evaluation: `bradycardia`, `hypoxia`, `combined`.
- **`training_curves.png`** — Training and validation loss curves.
- **`evaluation_plots.png`** — Evaluation visualisation plots.
- **`error_by_type.png`** — Reconstruction error distribution by anomaly type.
- **`anomaly_timeline.png`** — Timeline of anomaly scores across the test set.

> **Note:** `model.keras` and `scaler.pkl` are listed in `.gitignore` and must be regenerated by running the training notebook.
